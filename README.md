# 444 — Илья × Полина

Персональный статический сайт-подарок.

### Важно
В папке `assets` находятся только исходные фотографии и рукописная подпись:
- `photo-1.jpg`
- `photo-2.jpg`
- `signature.png`

Никаких сгенерированных фотографий в проекте нет.

### GitHub Pages
`index.html` должен лежать в корне репозитория, а папка `assets` — рядом с ним.

Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Сайт адаптирован для телефона и не требует сервера.
